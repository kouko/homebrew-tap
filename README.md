# Homebrew Tap

Homebrew formulae for [kouko](https://github.com/kouko) projects.

## Install

```bash
brew install kouko/tap/ytss
```

## Formulae

| Formula | Description |
|---------|-------------|
| [ytss](https://github.com/kouko/youtube-summarize-scraper) | YouTube batch subtitle scraper with whisper transcription and LLM summaries |
