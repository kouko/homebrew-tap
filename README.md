# Homebrew Tap

Homebrew formulae for [kouko](https://github.com/kouko) CLI tools.

## Usage

```bash
brew tap kouko/tap
```

## Formulae

| Formula | Install | Description |
|---------|---------|-------------|
| [metr](https://github.com/kouko/meeting-emo-transcriber) | `brew install kouko/tap/metr` | Meeting transcriber with speaker identification and emotion recognition |
| [rlss](https://github.com/kouko/reading-list-summarize-scraper) | `brew install kouko/tap/rlss` | Fetch Safari/Chrome Reading Lists, extract content, summarize with LLM to Obsidian Markdown |
| [ytss](https://github.com/kouko/youtube-summarize-scraper) | `brew install kouko/tap/ytss` | YouTube batch subtitle scraper with whisper transcription and LLM summaries |
